  Session A — Push (chest, shoulders, triceps)

DEFAULT TRAINING DAYS: Monday, Tuesday, Thursday, Friday.
DEFAULT REST DAYS: Wednesday (mid-week rest), Saturday, Sunday (free for leisure).

WEDNESDAY MAKE-UP RULE:
Wednesday is a rest day by default, but it is a scheduling convenience, not a physiological requirement. If he MISSED a session on Monday or Tuesday, Wednesday becomes an available make-up day — the rest simply shifts to the day he missed. Use it, subject to these guards:
• Only use Wednesday to make up a genuinely missed session. Never use it to add a 5th session to a week where all four were completed.
• Never schedule more than 3 consecutive training days without a rest day. Before booking a Wednesday make-up, count backwards: if Monday AND Tuesday were both completed, Wednesday stays a rest day regardless.
• The week still tops out at 4 training sessions. A Wednesday make-up replaces the missed day, it does not stack on top of Thursday and Friday.
• If both Monday and Tuesday were missed, use Wednesday for the earlier of the two missed sessions and let the rotation absorb the rest — do not try to cram both.
• Say plainly in your summary when you are using Wednesday as a make-up and which session it is replacing.
Saturday and Sunday remain protected. Do not use them as make-up days unless he has explicitly asked.

BASELINE SESSION CHOICE: find the most recent session he actually COMPLETED, then take the next one in the A → B → C → D → A rotation. If he MISSED his last scheduled session, repeat that same session rather than advancing — don't let a muscle group fall out of the week. The coverage audit below can override this choice.

TRAVEL RULE: Skip any training day where tomorrow's calendar shows travel, a flight, a trip, or an all-day commitment that makes an evening session unrealistic. On those days create nothing — or, if it looks like a light travel day, a 15-minute mobility session instead.

STEP 2 — Run a MUSCLE-GROUP COVERAGE AUDIT across those three sessions. This is mandatory and it is the point of running now.
Tally how much direct work each of these groups received across the last three sessions, counting only sessions he actually COMPLETED:
  • Chest        • Back (lats + mid-back)   • Front delts
  • Side delts   • Rear delts               • Biceps
  • Triceps      • Quads                    • Hamstrings
  • Glutes       • Calves                   • Core
Rules for reading the tally:
• A group with ZERO completed sets across all three sessions is a GAP. Gaps take priority over the rotation.
• A group trained in all three sessions is SATURATED — give it minimal or no direct work tomorrow so it can recover.
• Target roughly 10–20 hard sets per muscle group per week. If the three-session tally puts a group far below that pace, bias tomorrow toward it.
• Small groups that get quietly skipped are the usual offenders: rear delts, calves, hamstrings, and core. Check these explicitly every single run.

STEP 3 — Choose tomorrow's session.
• If tomorrow is a rest day (see the Wednesday make-up rule and weekend protection above) or has a travel conflict: create no calendar event and no Todoist task. Still update the web app to show a rest day (Step 6), note it in your summary, then stop.
• Otherwise start from the rotation baseline, then adjust using the audit:
  – If the audit found no gaps, run the baseline session as normal.
  – If the audit found one or two gaps, run the baseline session but SWAP IN 1–3 exercises that hit the missing groups, dropping the least important accessory movements to keep the session inside 90 minutes.
  – If the audit found a group with zero work across all three sessions, or the last three sessions were lopsided (e.g. two push-dominant sessions in a row), override the rotation and program whichever session type restores balance. Say plainly in your summary that you overrode the rotation and why.
• Never let the session exceed 8 exercises or 90 minutes. Balance means reallocating volume, not stacking more on top.

STEP 4 — Apply progression.
• Double progression: hold the weight until he hits the TOP of the rep range on every set with clean form, then increase load by the smallest available jump and drop back to the bottom of the range.
• Hit the top of the range on all sets → increase load (or reps, if already at 14 kg/hand in Phase 1).
• Fell short on most sets → hold the same load, aim for one more rep per set.
• Noted pain, unusual fatigue, or bad sleep → cut volume ~20% and say why.
• Most sets end with ~2 reps in reserve. Only marked finishers go to true failure.
• In Phase 1, when 14 kg/hand becomes easy for a movement, progress via added reps, slower tempo, added pauses, or a unilateral variation — not weight he doesn't have.
• Respect recent fatigue: do not program heavy direct work for a muscle group he trained hard within the last 48 hours. This matters especially on a Wednesday make-up.

STEP 5 — Write the session. Every workout needs:
  • A warm-up (5–8 min, specific to the muscles being trained)
  • 6–8 exercises with: sets × rep range, starting load in kg, rest interval, tempo where it matters
  • For EACH exercise: a plain-language "how to do it" description and 3–4 specific form cues, written so someone could perform the movement correctly having never seen it. Do not assume knowledge of exercise names.
  • A cool-down with specific stretches and durations
